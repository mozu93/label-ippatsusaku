# 印刷開始位置指定 設計書

**作成日:** 2026-07-06
**対象バージョン:** 次期リリース（予定）

---

## 1. 概要

宛名ラベル用紙（A-ONE 28185 / 28187 / 51002）は複数面（18面・12面・10面）のシールが1枚の台紙に配置されている。実際の運用では台紙を使い切らず、一部の面だけ印刷済みの「使いかけシート」が発生することが多い。現状は常に1面目（左上）から印刷されるため、使いかけシートを再利用しようとすると印刷済みの面に重ねて印字してしまい、シートを無駄にしてしまう。

本機能は、PDF生成時に「何面目から印刷を開始するか」を指定できるようにし、使いかけシートの空いている面から印刷できるようにする。

---

## 2. 仕様詳細

### 2.1 対象レイアウト

対象: `a_one_28185`（18面）、`a_one_28187`（12面）、`a_one_51002`（10面）
対象外: `a4_4split`（卓上プレート）— A4用紙にそのまま印刷する特殊構造（1エントリが2スロット・上下回転ペアで展開される）のため、開始位置の概念がなじまない。常に先頭から出力する。

### 2.2 面番号の数え方

各レイアウトの並び順（左上を1面目とし、左→右・上→下の順）に一致させる。これは既存の `_label_origin()` が使っている `col`/`row` の走査順（`page_slot = slot % per_page; col = page_slot % cols; row = page_slot // cols`）と同一であり、新たな順序を定義する必要はない。

### 2.3 PDF生成ロジック（`app/services/label_pdf_service.py`）

`generate_label_pdf()` に引数を追加する:

```python
def generate_label_pdf(
    entries:         list,
    output_path:     str,
    batch_mode:      str   = "normal",
    layout_key:      str   = DEFAULT_LAYOUT_KEY,
    font_key:        str   = DEFAULT_FONT_KEY,
    barcode_enabled: bool  = False,
    offset_h_mm:     float = 0.0,
    offset_v_mm:     float = 0.0,
    start_slot:      int   = 0,
) -> str:
```

- `layout_key == "a4_4split"` の場合、渡された `start_slot` の値に関わらず `0` として扱う（呼び出し側の値を無視する。呼び出し側でも明示的に0を渡す設計とし、二重の安全策とする）
- それ以外のレイアウトでは、`per_page = layout.cols * layout.rows` の範囲に `start_slot` をクランプする（`max(0, min(start_slot, per_page - 1))`）。範囲外の値（負数・面数以上）を渡されても安全に動作させるため
- ループ内の初期値 `slot = 0` を `slot = <クランプ後の start_slot>` に変更する。これ以外のロジック（ページ送り判定 `slot % per_page == 0`、`col`/`row` 計算）は一切変更しない — スロットカウンタの初期値だけがずれるので、2枚目以降のページは常に1面目から通常通り埋まる

### 2.4 UI（`app/ui/direct_label_dialog.py`）

- フッターの「用紙:」コンボの右に「**開始位置:**」ラベルと `QSpinBox` を追加する
  - 範囲: 1 〜 現在選択中レイアウトの面数（`layout.cols * layout.rows`）
  - 初期値: 常に1（ダイアログを開くたびにリセットされる。値の永続化は行わない）
  - 用紙コンボを切り替えるたびに最大値を再設定し、現在値が新しい面数を超えていたら面数に丸める
- `layout_combo` が `a4_4split` を選択している間はこのスピンボックスを非表示にする（卓上プレートは開始位置の概念がないため）
- `_preview_pdf()` と `_export()` の両方で、`generate_label_pdf()` 呼び出し時に `start_slot=スピンボックスの値 - 1` を渡す。ただし選択中レイアウトが `a4_4split` の場合は `start_slot=0` を明示的に渡す

### 2.5 スコープ外

- 開始位置の値をアプリ再起動後や次回ダイアログオープン時に記憶する機能（ご回答により対象外。誤った値のまま気づかず印刷してしまう事故を防ぐため、常に1面目にリセットする）
- 卓上プレート（A4横長4分割）への適用

## 4. テスト

`tests/test_label_pdf_service.py` に追加:
- `start_slot` を指定した場合、最初のエントリが `_label_origin(col, row, ...)` の該当スロット座標（`start_slot` から導出される `col`/`row`）に描画されることを確認するテスト
- 面数ちょうどで開始位置を指定し（例: 18面用紙で `start_slot=17`）、2件のエントリを渡すと1件目が最終面、2件目が2ページ目の1面目に描画される（ページをまたぐ）ことを確認するテスト
- `start_slot` に面数以上の値・負の値を渡してもクランプされ、例外にならないことを確認するテスト
- `layout_key="a4_4split"` の場合、`start_slot` に何を渡しても常に1面目（通常の座標）から描画されることを確認するテスト

`direct_label_dialog.py` 側はPyQt UIで自動テスト対象外のため、実装後に実際にアプリを起動し、用紙ごとに開始位置スピンボックスの最大値が正しく切り替わること、卓上プレート選択時に非表示になること、プレビュー/PDF出力の両方で指定した面から描画されることを手動確認する。
