## 1. 概要

**ラベル一発作成**は、ExcelやCSVのデータから宛名ラベル・名札・卓上プレートのPDFを素早く作成するアプリです。

### できること

- 宛名ラベル（氏名あり・氏名なし・事業所名のみ）
- 名札（A-ONE 51002 対応）
- 卓上事業所名プレート（A4横長4分割・裁断ガイド付き）
- Excelからコピー＆貼り付けでデータ取込
- CSVファイルからデータ取込
- 住所・事業所名を2行に分けて入力（住所1/住所2、事業所名/事業所名2）
- 郵便番号の自動補完（住所から検索）
- フリガナの自動補完
- 保存前のPDFプレビュー表示
- 印刷位置のズレを補正する機能

## 2. 基本的な使い方

### 手順の流れ

```
① アプリを起動（一覧画面が表示される）
② 「何を作りますか？」のカードから作りたいラベルの種類を選ぶ
　　（一覧画面が空の場合は「＋ 新規作成」ボタンでも開始できます）
③ データ名を入力
④ 必要ならモードを変更
⑤ データを取り込む（貼り付け・CSV・手入力）
⑥ 必要に応じて編集・補完
⑦ 「👁 プレビュー」で仕上がりを確認
⑧ 「PDF を出力する」をクリック
```

### 起動方法

以下のいずれかの方法でアプリを起動します。

- **デスクトップ**の「ラベル一発作成」ショートカットをダブルクリック（インストール時にショートカット作成を選んだ場合）
- **スタートメニュー** →「ラベル一発作成」をクリック

## 3. モードの選び方

一覧画面の「何を作りますか？」カード、または新規作成ダイアログ上部のボタンでモードを選択します。

> モードを選択すると、そのモードで**必須のデータ列がピンク色でハイライト**されます。ハイライトされていない列（郵便番号・フリガナ・所属・役職名・住所2・事業所名2など）は任意入力です。

| モード | 出力内容 | 用途 |
|--------|---------|------|
| **宛名（氏名あり）** | 郵便番号・住所1・住所2・事業所名・事業所名2・役職・氏名　様 | 個人宛の封書 |
| **宛名（氏名なし）** | 郵便番号・住所1・住所2・事業所名・事業所名2　御中 | 法人宛の封書 |
| **事業所名のみ** | 事業所名・事業所名2　御中 | 社内便・簡易ラベル |
| **名札** | 事業所名・事業所名2・役職・氏名（大きめ） | 会議・研修の名札 |
| **卓上プレート** | 事業所名を均等割付（上下反転セット・裁断ガイド付き） | 卓上プレート |

### モード別の推奨用紙

| モード | 推奨用紙 |
|--------|---------|
| 宛名（氏名あり・なし・事業所名のみ） | A-ONE 28185 または A-ONE 28187 |
| 名札 | A-ONE 51002 |
| 卓上プレート | A4 横長4分割 |

> モードを選ぶと用紙の選択が自動的に切り替わります。

## 4. データの取り込み方

### 4-1. Excelから貼り付ける（推奨）

1. Excelでデータ範囲を選択してコピー（Ctrl+C）
2. アプリの「**貼り付けから取込**」ボタン（または **Ctrl+V**）をクリック
3. **列の対応を設定**ダイアログが開くので、各フィールドに対応する列を選択
4. 「取込む」をクリック

> ダイアログでは「**任意**」と表示のあるフィールドは省略できます。事業所名2・住所2は常に任意です。

**認識される見出し名（ヘッダーあり取込の場合）:**

| フィールド | 認識される見出し名の例 |
|-----------|----------------------|
| 事業所名 | 企業名 / 会社名 / 事業所名 |
| 事業所名2 | 事業所名2 / 会社名2 |
| フリガナ | フリガナ / 読み / よみ / ふりがな |
| 郵便番号 | 郵便番号 |
| 住所1 | 住所 / 住所1 |
| 住所2 | 住所2 |
| 所属・役職名 | 肩書 / 所属 / 役職 / 部署 / 所属・役職 |
| 氏名 | 氏名 / 名前 / 担当者 |

> 見出し名が上記に一致しない列は、「列の対応を設定」ダイアログで手動で選択してください。

ヘッダー行がない場合は列数で自動判定します（この場合、事業所名2は自動判定の対象外です）：

| 列数 | 自動割り当て |
|------|------------|
| 2列 | 事業所名、氏名 |
| 3列 | 事業所名、肩書、氏名 |
| 4列 | 事業所名、住所1、肩書、氏名 |
| 5列 | 事業所名、郵便番号、住所1、肩書、氏名 |
| 6列 | 事業所名、郵便番号、住所1、住所2、肩書、氏名 |

### 4-2. CSVから取り込む

1. 「**CSV 取込**」ボタンをクリック
2. CSVファイルを選択
3. **列の対応を設定**ダイアログで列を割り当て
4. 「取込む」をクリック

> 文字コードは UTF-8 / Shift-JIS どちらも自動判定します。
> Excelで `="510-0211"` のように保存された郵便番号は、自動的に `510-0211` として取り込まれます。

### 4-3. 手動で行を追加する

「**＋ 追加**」ボタンで空行を追加し、各セルを直接入力できます。

表の列（左から）: 事業所名 / 事業所名2 / フリガナ / 所属・役職名 / 氏名 / 郵便番号 / 住所1 / 住所2

- **事業所名**・**所属・役職名** のセルは改行（Alt+Enter）に対応しています
- 入力確定は Enter または Tab

### 4-4. 既存データに追記する

取り込み時に既存データがある場合は確認ダイアログが表示されます：

- **上書き**: 現在のデータをすべて削除して取り込む
- **追記**: 現在のデータの後ろに追加する

### 4-5. データの修正・取り消し

| 操作 | 方法 |
|------|------|
| 行を削除 | 削除したい行を選択 → 「**行を削除**」ボタン |
| 全件削除 | 「**全クリア**」ボタン → 確認ダイアログで「はい」 |
| 操作を取り消す | 「**↩ 元に戻す**」ボタン または **Ctrl+Z** |

「元に戻す」は取込・行削除・全件クリアの操作を最大10段階まで遡って取り消せます。

## 5. 補完機能

### 5-1. 郵便番号を自動入力

住所1が入力されていて郵便番号が空の行を対象に、インターネット経由で郵便番号を検索・補完します。

1. 「**〒 自動補完**」ボタンをクリック
2. 自動補完が実行される（インターネット接続が必要）
3. 完了後、補完件数と未特定件数が表示される

> 郵便番号が特定できなかった行は手動で入力してください。住所2（建物名・部屋番号など）は検索には使用されません。

### 5-2. フリガナを自動入力

事業所名が入力されていてフリガナが空の行を対象に、カタカナのフリガナを自動生成します。

1. 「**フリガナ補完**」ボタンをクリック
2. 完了後、補完件数が表示される

> 株式会社・有限会社などの法人格は除いて変換されます。

## 6. PDF出力・プレビュー

### プレビュー機能

「**👁 プレビュー**」ボタン（または **Ctrl+P**）をクリックすると、PDFを保存せずに仕上がりを画面上で確認できます。データを微調整しながら何度でも確認できます。

### 出力手順

1. データを確認する（チェックボックスがオンの行だけ出力されます）
2. 画面下部で**用紙**と**フォント**を選択する
3. 必要であれば「👁 プレビュー」で確認する
4. 「**PDF を出力する**」ボタンをクリック
5. 保存先とファイル名を指定する
6. 出力完了後、PDFを開くか確認ダイアログが表示される

> チェック済みの行に必須項目（事業所名・氏名・住所1など）が未入力の場合、出力前に警告が表示されます。そのまま出力することも、キャンセルして修正することもできます。

### 出力対象の選択

- テーブル左端のチェックボックスで行ごとに出力のオン/オフを切り替えられます
- ヘッダー行のチェックボックスで全行をまとめてオン/オフできます
- **Shift+クリック**で範囲選択ができます

### 保存先フォルダの変更

ダイアログ下部の「保存先:」に現在の保存先フォルダが表示されます。フォルダ名クリック、または「**変更**」ボタンで保存先を変更できます。次回以降もこの保存先が使用されます。

### 卓上プレートモードの特記事項

A4用紙横長4分割で出力します。上下を逆向きにした2枚が1セットで印刷されるため、半分に折って両面から読めるプレートになります。用紙右端から内側に、切り取り位置の目安となる点線（裁断ガイド）が印刷されます。

## 7. 印刷位置の補正

シール台紙とプリンターの相性によって、印刷内容とシールの枠が微妙にずれることがあります。この場合は印刷位置補正機能で調整できます。

1. メニューの「**ファイル**」→「**印刷位置補正...**」を開く
2. 用紙ごと（A-ONE 28185・A-ONE 28187・A-ONE 51002）に横補正・縦補正の値（mm単位）を設定する
3. 「保存」をクリックすると、以降のPDF生成すべてに自動的に反映される

**補正の目安:**

| ずれの方向 | 対応 |
|-----------|------|
| 内容が右にずれる | 横補正を負の値に |
| 内容が左にずれる | 横補正を正の値に |
| 内容が下にずれる | 縦補正を負の値に |
| 内容が上にずれる | 縦補正を正の値に |

> 卓上プレート（A4横長4分割）はこの補正の対象外です。A4用紙にそのまま印刷するため、ズレの調整は不要です。

| A-ONE 28187 | A-ONE 28187 | 84×42mm | 2列×6行（12面） |
| A-ONE 51002 | A-ONE 51002 | 91×55mm | 2列×5行（10面・名札） |

> フォントの一覧は、お使いのパソコンにインストールされているものだけが表示されます。フォントが見当たらない場合はWindowsに未インストールの可能性があります。

## 9. データの管理（一覧画面）

### 「何を作りますか？」カード

一覧画面上部の5種類のカード（宛名ラベル 氏名あり／宛名ラベル 氏名なし／事業所名のみ／名札／卓上プレート）をクリックすると、そのモードを選んだ状態で新規作成ダイアログが開きます。

### 検索・絞り込み

- **検索欄**（🔍 ラベル名で検索）に入力すると、ラベル名で絞り込まれます
- **モードフィルター**で特定のモードのデータだけを表示できます

### 一覧テーブルの操作

| 操作 | 方法 |
|------|------|
| 編集（再出力） | 行をダブルクリック、または「**開く**」ボタン |
| 保存済みPDFを開く | 「**PDF**」ボタン（PDFを未出力の行では無効） |
| 削除 | 行の「**削除**」ボタン |
| 複数削除 | チェックボックスで選択 → 「**チェックした項目を削除**」 |
| 並び替え | 列ヘッダーをクリック（クリックのたびに昇順/降順が切り替わります） |

テーブルの列は「チェック・ID・ラベル名・件数・モード・作成日時・操作」です。データ件数が多い場合は、画面下部のページ送りで表示を切り替えます。

### データの保存場所

データベースは以下に保存されます：

- **インストール済み版**: `%APPDATA%\LabelIppatsusaku\label_ippatsusaku.db`
- **開発版（bat起動）**: アプリのフォルダ直下

## 10. よくある質問

**Q. 印刷位置がずれる**
A. まず「ファイル」→「印刷位置補正...」で用紙ごとの横補正・縦補正を調整してください（[7. 印刷位置の補正](#7-印刷位置の補正)参照）。それでも改善しない場合は、お使いのプリンターのプロパティで「実際のサイズ」「拡大縮小なし」に設定してください。PDFビューアーの印刷設定でも「ページに合わせる」ではなく「実際のサイズ」を選択してください。

**Q. 郵便番号の自動入力が動かない**
A. インターネット接続が必要です。社内ネットワークのプロキシ設定が原因の場合は、IT担当者にご相談ください。

**Q. フリガナが正しく変換されない**
A. 固有名詞や特殊な読みは自動変換が難しいことがあります。変換後のフリガナを手動で修正してください。

**Q. 事業所名が長くて1行に収まらない**
A. 事業所名セルを編集して、折り返したい箇所で **Alt+Enter** を入力すると任意の位置で改行できます。

**Q. 住所や事業所名を2行に分けたい**
A. 直接入力の表には「住所1」「住所2」「事業所名」「事業所名2」の列があります。建物名・部屋番号や支店名などは2番目の列に分けて入力してください。貼り付け・CSV取込の場合は、見出し名を「住所2」「事業所名2」にするか、「列の対応を設定」ダイアログで該当する列を選択してください。

**Q. 氏名に役職名や敬称を含む長いテキストを入れると表示が崩れる**
A. 「役職名＋氏名＋様」のような長いテキストを氏名欄に入れた場合、自動的に2行に折り返して表示されます。氏名がすでに「様」で終わっている場合は、敬称が重複して付くことはありません。

**Q. 出力したいデータだけを選びたい**
A. 各行左端のチェックボックスを使って出力対象を選択してください。チェックがオフの行はPDFに出力されませんが、データとして保存はされます。

**Q. アプリが自動更新されない**
A. アプリ起動時に上部にアップデート通知が表示されます。通知が表示された場合は案内に従ってインストーラーを実行してください。
